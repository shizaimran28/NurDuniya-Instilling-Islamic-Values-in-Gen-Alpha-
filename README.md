# NurDuniya-Instilling-Islamic-Values-in-Gen-Alpha-
Nur Duniya is a web-based platform designed to make Islamic learning more engaging and accessible through stories and educational lessons.

Explore the live website: **[Nur Duniya](https://nurduniya.netlify.app/)**

## About the Project

Nur Duniya is a website focused on Islamic learning and educational content. The project aims to provide visitors with an accessible online experience for exploring Islamic stories and lessons through a dedicated web platform.

## Key Highlights

- Islamic learning and educational content
- Stories and lessons presented through a dedicated website
- Interactive learning experience
- Accessible through a web browser
- Live deployment hosted on Netlify
